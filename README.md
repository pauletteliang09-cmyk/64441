# Research Methods (64441) Final Exam Revision

Interactive open-lecture slides by Phoenix EDU: what the final exam looks like, what it tests, three worked example questions, dos and don'ts, and FAQ.

## Presenting
| Key | Action |
|---|---|
| ← → / Space | Previous / next slide |
| O | Slide overview |
| F | Full screen |
| P | Pen on/off (H highlighter, E eraser, C clear slide, Esc stop) |
| N | Speaker notes panel (editable) |
| V | Presenter window: notes, timer, next slide; stays in sync with the main window |
| S | Add a sticky note to the current slide |

Drawings, sticky notes and edited speaker notes are saved in your own browser only.
